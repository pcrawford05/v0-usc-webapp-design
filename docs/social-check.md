# Social media check (Instagram + LinkedIn)

Run from a session on your computer with Claude in Chrome connected (it uses your logged-in Instagram and LinkedIn). Read only; never follow, like, message or post.

## Prompt

> Using Claude in Chrome, work through docs/social-check.md. For each program, find its Instagram and LinkedIn pages (search each site if no handle is listed), read the bio and the last ~6 months of posts, and record: who can join (undergrad, grad, PhD, alumni), recruiting or application dates, upcoming events, and whether it still looks active. Do not follow, like, message or post. Save results to docs/research-runs/social-<date>.json as [{id, instagram, linkedin, active, eligibility, dates, events, evidence:[{url, quote}]}], then apply only facts with a quoted post or bio to data/programs.json (audience only when stated), add the profile URLs to data/sources.json as kind "social", and open a PR.
